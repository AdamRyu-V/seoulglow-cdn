# seoulglow-cdn

Public image host for **@the_seoul_glow** Instagram carousel auto-publishing.

The Instagram Graph API fetches carousel images over public HTTPS, so these JPEGs
must stay publicly readable. Served via jsDelivr:

    https://cdn.jsdelivr.net/gh/AdamRyu-V/seoulglow-cdn@main/seoulglow/<file>.jpg

Publisher runtime: `AdamRyu-V/aesthetik-publisher` (private).
Authoring source: `FORGE_Cowork/build/ig-auto-publisher/`.
